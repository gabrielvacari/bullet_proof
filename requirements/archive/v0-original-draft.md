# Bullet Proof - Multiplayer Game

## Requirements

1. 2 Methods - Free for all & Team deathmatch
2. TDM - blue vs red
2. 10 max players per server
3. Before get into the game, must provide a nickname
4. 5 Shots to die
5. Life is 100 and there is no bulletproof vest
6. third person view
7. Walls to player defend their selfs. 
8. If a player is inside a room the other one cannot see where he is. 


## Tech Requirements

1. Web Browser Game
2. Node.js
3. WebSocket
4. LocalStorage
