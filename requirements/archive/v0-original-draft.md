# Bullet Proof - Multiplayer Game

## Requirements

1. 2 Methods - Free for all & Team deathmatch
2. TDM - blue vs red
3. 10 max players per server
4. Before get into the game, must provide a nickname
5. 5 Shots to die
6. Life is 100 and there is no bulletproof vest
7. third person view
8. Walls to player defend their selfs.
9. If a player is inside a room the other one cannot see where he is.

## Tech Requirements

1. Web Browser Game
2. Node.js
3. WebSocket
4. LocalStorage
